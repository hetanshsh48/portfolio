# Interview Talking Points

## Project Narrative
- Sourced public CMS HRRP data and hospital attributes to analyze readmission patterns.
- Built automated ETL in Python: ingestion, cleaning/validation, and feature engineering.
- Modeled a star schema for scalable BI reporting.
- Authored complex SQL (CTEs, window functions) for benchmarking and trending analysis.
- Translated findings into operational recommendations with KPI targets.

## Why It’s Relevant
- Demonstrates healthcare analytics experience.
- Shows ability to work with public datasets and create BI-ready models.
- Highlights SQL and Python proficiency expected in US data analyst roles.

## Deep-Dive Prompts
- How did you validate the data quality and handle missing readmission measures?
- How did you design your dimensions to support future dashboarding?
- What were the key operational levers you proposed for readmission reduction?

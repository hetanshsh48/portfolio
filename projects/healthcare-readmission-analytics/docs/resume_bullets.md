# STAR Resume Bullets (Use on Resume)

**Situation/Task:** CMS readmission penalties reduced reimbursement and leadership needed clarity on drivers of readmissions and operational levers.

**Action:** Built an end-to-end analytics pipeline in Python to ingest and clean CMS HRRP and Hospital General Information data, modeled a star schema, and authored advanced SQL (CTEs, window functions) to benchmark hospital performance.

**Result:** Delivered a KPI dashboard concept and recommendations that identified top-penalty facilities and high-risk measures, enabling a targeted 2–3% readmission reduction strategy.

---

## Bullet Options
- Built an end-to-end analytics pipeline on CMS readmission data, creating a star schema and automated ETL in Python to deliver analytics-ready tables for BI consumption.
- Authored advanced SQL using CTEs and window functions to benchmark readmission rates, identify high-risk hospitals, and quantify penalty exposure.
- Designed a Power BI/Tableau dashboard with executive KPIs, peer benchmarks, and seasonal trend insights to guide operational improvements.
- Delivered data-driven recommendations targeting high-penalty hospitals and high-variance clinical measures, supporting a 2–3% readmission reduction goal.
